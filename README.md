# COVID-19 Data Analysis Dashboard (Excel)
<!--demo changes-->
## Project Overview
This project presents an interactive data analysis dashboard built using Microsoft Excel to analyze global COVID-19 data. The dashboard provides insights into confirmed cases, recoveries, and deaths across different regions using data visualization techniques.

## Objectives
- Analyze COVID-19 data trends
- Visualize pandemic statistics effectively
- Create an interactive dashboard for easy data interpretation

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Charts and Graphs
- Data Cleaning and Data Visualization

## Features
- Global COVID-19 case analysis
- Country-wise comparison of confirmed cases, recoveries, and deaths
- Interactive charts and dashboards
- Data-driven insights using pivot tables

## Dataset
The dataset contains COVID-19 statistics including:
- Confirmed Cases
- Deaths
- Recoveries
- Country/Region
- Date-wise statistics

## Dashboard Insights
The dashboard helps in:
- Understanding pandemic growth trends
- Comparing different countries' COVID-19 impact
- Visualizing key statistics in an easy-to-understand format

## Future Improvements
- Integration with Power BI for advanced visualization
- Real-time data updates
- Additional analytics for prediction modeling
